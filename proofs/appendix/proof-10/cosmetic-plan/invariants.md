# Invariants

## Invariants

- INV-1 [L0] All existing sections, links (hrefs and targets), and forms (fields, actions,
  handlers) on the landing page must remain unchanged by this work.
- INV-2 [L0] Every testimonial card that exists today must remain present in the DOM and be shown
  by the rotation cycle; auto-rotation must never drop or hide a testimonial permanently.
- INV-3 [L0] The accent color change must be applied at the token/variable level so no element is
  left half-orange; no non-accent colors change.
- INV-4 [L0] When the user prefers reduced motion (or is hovering/focusing the carousel), the
  testimonials must not auto-advance, and all cards must still be reachable manually.
- INV-5 [L0] The hero headline must render the exact string "Train with the best in the
  Lowcountry" — no truncation or re-wording.
